# ☕ Java Fundamentals

A well-structured repository for learning, revising, and practicing **Core Java** concepts with clean code examples and concise notes.

This repository is designed for:

* 📘 **Java revision**
* 💼 **Interview preparation**
* 🧠 **Concept reinforcement through code**
* 🚀 **Building a strong GitHub portfolio**

---

## 📚 Topics Covered

### 1. Java Basics

* JDK, JRE, JVM
* Compilation process
* Variables and data types
* Operators
* Input/Output
* Methods and packages

### 2. Object-Oriented Programming

* Classes and objects
* Constructors
* Inheritance
* Polymorphism
* Abstraction
* Encapsulation
* Interfaces

### 3. Strings and Arrays

* String methods
* StringBuilder and StringBuffer
* One-dimensional and multidimensional arrays

### 4. Exception Handling

* try-catch-finally
* throw and throws
* Custom exceptions

### 5. Collections Framework

* ArrayList
* LinkedList
* HashSet
* TreeSet
* HashMap
* PriorityQueue

### 6. Generics

* Generic classes
* Generic methods
* Wildcards

### 7. Java 8+ Features

* Lambda expressions
* Functional interfaces
* Stream API
* Method references
* Optional

### 8. File Handling

* File class
* BufferedReader / BufferedWriter
* Serialization basics

### 9. Multithreading

* Thread class
* Runnable interface
* Synchronization
* Executor framework basics

### 10. JDBC

* Database connection
* PreparedStatement
* CRUD operations
* Transaction handling basics
